## Safety reason

a review bot (vendor docs, 2026-10-31): safe. Official product of Promptfoo (now part of OpenAI), MIT. Collects basic usage telemetry by default (commands, assertion types; plus your email if logged in to promptfoo cloud); turn off with `PROMPTFOO_DISABLE_TELEMETRY=1`. Red-team runs send attack prompts to the models you point it at.

## Safe install

Safe install (fixes applied):
Claude Code (Windows, local only): set PROMPTFOO_DISABLE_TELEMETRY=1 and PROMPTFOO_DISABLE_UPDATE=1 first (promptfoo.dev telemetry page: telemetry is on by default; the update check asks npm on every run), plus PROMPTFOO_DISABLE_REMOTE_GENERATION=true for red-team runs so attack prompts are generated by your own model, not Promptfoo-hosted generation (CLI docs). Then run it pinned without a global install: npx promptfoo@0.125.1 init and npx promptfoo@0.125.1 eval (0.125.1 is the latest on npm, 2026-11-16). Provider keys go in environment variables only. Do not use promptfoo share unless you want results uploaded. Red-team runs send attack prompts to the model you point it at: point it only at models and endpoints you own.

## YOLO install

YOLO (your own risk): skips the telemetry and update opt-outs and the pin.
npm install -g promptfoo (README; global, latest), default telemetry and remote generation on.

## Install notes

Claude Code (local only): `npm install -g promptfoo` (or `brew install promptfoo` / `pip install promptfoo`); set `PROMPTFOO_DISABLE_TELEMETRY=1` first (`promptfoo.dev` docs).
