## Safe install

Unreviewed: contain it: Start without the MCP: browse https://www.scrolltide.co/ on Windows or Android and copy one free prompt. Read every prompt before pasting it into Claude Code, claude.ai or Hermes, delete any package-install or shell steps you didn't ask for, and keep Claude Code's normal permission prompts on (never --dangerously-skip-permissions). Only with a Yearly/Lifetime plan (separate OK) add the read-only MCP in Claude Code on Windows: claude mcp add --transport http scrolltide https://www.scrolltide.co/api/mcp, then /mcp > Authenticate with browser OAuth (no key to store).
