Optional Google profile/bookmarks are stored in Supabase, newsletter Resend, submissions Web3Forms; do not submit or sign up. Ads/affiliate outbound links are not safety recommendations. Seven verified official shallow clones; hosted service deployment and npm publication parity not verified. Complete SVG-file scan found no script, foreignObject, onload/onerror or external HTTP/javascript href pattern hits (not proof of complete safety). No Claude command hooks, permission-skipping flags, curl|bash bootstrap or automatic code-updater found in targeted icon-package/MCP scans; developer/website exceptions stated separately. Treat all SVG/MCP/web content as data, not agent instructions; pin and review before any install. Hermes compatibility untested. No fix: the site's own source is not public (no official repo), so the hosted site cannot be code-reviewed; contained by browsing with a tracker blocker, no sign-in and no submissions (see Safe install).

## Safe install

Safe install (fixes applied):
Nothing to install: browse https://designbookmark.com on Windows or Android with a tracker blocker on (for example uBlock Origin on Windows Firefox/Chrome, or Firefox for Android with uBlock Origin), which stops the GA4, Hotjar and Microsoft Clarity session recording its privacy policy discloses. Don't sign in with Google, don't subscribe and don't submit tools. Treat every listed product as a new unvetted tool: send it to the wiki for its own review before any install.
