## Safety reason

Claude docs read (2026-11-19): hosted paid library with no public source. Its /privacy (sections 2, 5, 7) says uploads go to Cloudflare R2 and IP/device logs are kept about 90 days. Unverified: the site code and the prompts' effect on agents -> Contain: browser only, upload nothing private, read each prompt before an agent sees it, permission prompts on.

## Safe install

Unreviewed: contain it: Nothing to install: browse https://sceneai.art/ in a browser on Windows or Android. If you buy access (separate OK needed), use it in the browser only and upload nothing private: per /privacy sections 2, 5 and 7, uploads are stored on Cloudflare R2 and IP/device/page logs are kept about 90 days. Read each prompt before pasting it into Claude Code or claude.ai, and keep Claude Code's normal permission prompts on (never --dangerously-skip-permissions), so a prompt can't install packages or run commands without your OK. Hermes: same pasted text, untested. Don't resell prompts or assets or use them for AI training (/license sections 2-6). Get a review before real use.
