## Safety reason

Paid UI prompt/design-asset library for landing pages, animated backgrounds and gradients. Not a native Claude skill/MCP discovered in reviewed pages; marketing reel is a catalog demo. Official /privacy sections 2,5,7 disclose uploads on Cloudflare R2, account/session data, IP/device/referrer/page/timestamp logs, MongoDB/Stripe/Google providers; server logs typically 90 days, backups up to 90 days after deletion. Do not upload private project/source/learner data. Prompt can direct an agent into unsafe installs or unrelated changes; inspect as untrusted data and keep project approvals. License sections 2-6 allow personal/client/commercial end products but prohibit asset/prompt resale, AI-model training and false original authorship; monthly-expiry survival covers assets already incorporated into a deployed project, not new projects after expiry. Preserve required notices. Hosted-site documentation review, not a runtime/dependency audit. Official implementation repo unknown after focused search; no source clone/code file:line claims, stars or last-commit metadata possible for this site. Hooks, shell/eval, telemetry SDKs, auto-updaters and downloaded code behavior are unverified, not assumed absent. Browsing makes normal web requests; no sign-up, purchase, download of paid assets, install or project execution. Treat prompts/snippets/links as data and obtain separate approval before dependency installs or commands. No fix: the hosted service keeps uploads and account/IP/device logs (/privacy sections 2, 5, 7) and its code is not public; contained by browser-only use, no private uploads and reading every prompt before an agent sees it.

## Safe install

Safe install (fixes applied):
Nothing to install: browse https://sceneai.art/ in a browser on Windows or Android. If you buy access (separate OK needed), use it in the browser only and upload nothing private: per /privacy sections 2, 5 and 7, uploads are stored on Cloudflare R2 and IP/device/page logs are kept about 90 days. Read each prompt before pasting it into Claude Code or claude.ai, and keep Claude Code's normal permission prompts on (never --dangerously-skip-permissions), so a prompt can't install packages or run commands without your OK. Hermes: same pasted text, untested. Don't resell prompts or assets or use them for AI training (/license sections 2-6).
