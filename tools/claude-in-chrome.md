## Safety reason

Anthropic docs (permissions guide, support.claude.com 12902446, checked 2026-11-14): safe with fixes. It reads, clicks and types in your own Chrome. Fix: set the side panel to 'Manually approve' (Claude asks before each action) instead of 'Automatically approve'; use 'Always allow actions on this site' only on read-only sites; run it in a separate Chrome profile with no banking or admin logins.

## Safe install

Safe install (fixes applied):
A separate Chrome profile; permission mode 'Manually approve'; no 'Always allow' except read-only sites.

## YOLO install

YOLO (your own risk): skips per-action approval.
'Automatically approve' mode in your main Chrome profile.
